Step-by-Step Breakdown
What Happens Inside Each Stage
Every box in the pipeline — unwrapped.
1
Content Generation
Engine: GPT-4o (OpenAI)
The system reads the brand guidelines and the last 10 post history entries to avoid repetition. GPT-4o is asked to act as a senior content strategist and return a structured JSON brief — complete with a theme, on-image headline in Albanian, and a full Instagram caption with hashtags.
Inputs
  • BRAND.md guidelines
  • Post history (last 10)
  • Business profile JSON
Outputs
  • Post type (tip / case study…)
  • Theme (English, internal)
  • Headline (Albanian)
  • Caption + hashtags
Anti-repetition logic Albanian text JSON output
2
Reference Image Selection
Engine: Local File System
Three real past posts are randomly sampled from the brand's uploaded content library. These serve as visual "style anchors" — showing the AI what the brand actually looks like in practice, not just what the guidelines say. This dramatically improves visual consistency across all output.
Inputs
  • uploaded_posts/ folder
  • All past brand images
Outputs
  • 3 random reference images
  • Passed to Gemini Vision
Visual style anchoring Brand consistency
3
Image Prompt Generation
Engine: Gemini Vision (Google)
Gemini Vision receives the 3 reference images, the content theme, the post headline, and the brand guidelines. It analyzes all of this to craft a precise, detailed generation prompt for Fal.ai — specifying scene concept, color palette, material textures, lighting style, object placement, and composition rules.
Inputs
  • 3 reference images
  • Content theme
  • BRAND.md
  • Post headline
Outputs
  • Visual concept (1 sentence)
  • Full Fal.ai prompt
  • Scene + lighting brief
Multimodal AI Brand-aligned prompting No text in image
4
Background Image Generation
Engine: Fal.ai (4 parallel calls)
Four background images are generated simultaneously using two different AI models in two modes each: with and without visual references. This creates a diverse set of options — some creatively free, others tightly aligned to brand history. The best are surfaced for selection.
Inputs
  • Fal.ai prompt
  • Reference images (optional)
  • 4:5 aspect ratio spec
Outputs
  • nano_noref.jpg
  • nano_ref.jpg
  • gpt_noref.jpg
  • gpt_ref.jpg
4 variants 1080×1350px 4K quality nano-banana-pro gpt-image-2
5
Text + Logo Overlay
Engine: Gemini Vision + Pillow
For each background, Gemini Vision analyzes the image and returns three different layout philosophies (bold, minimal, centered). The Python Pillow library then executes the chosen layout: placing the logo, sizing and wrapping the headline, drawing optional contrast overlays, adding the brand accent bar, and applying text shadows for maximum readability.
Inputs
  • 4 background images
  • Albanian headline
  • Gemini layout choices
Outputs
  • Logo placed (top center)
  • Headline rendered
  • Overlay + accent bar
  • 4 complete post images
3 layout options Poppins font Orange accent Text shadows
6
AI Quality Refinement Loop
Engine: Gemini Vision (iterative)
The completed post is sent back to Gemini Vision for a quality review. Gemini scores the design out of 10 and gives specific improvement notes. If the score is below 9, the layout parameters are adjusted and the image is re-rendered. This loop runs until the AI itself approves the result — or a maximum of 8 rounds.
Inputs
  • Rendered post image
  • Current layout settings
Outputs
  • Score /10
  • Design feedback
  • Updated layout params
  • Refined final image
Auto QA Score threshold: 9/10 Max 8 rounds
7
History Logging
Engine: Local JSON Database
Every generated post is catalogued with full metadata — post type, headline, caption, visual description, all image paths, colors used, and engagement placeholders. This history feeds back into Step 1 to prevent content repetition and maintain strategic variety across weeks of posting.
Inputs
  • All post metadata
  • 4 final image paths
  • Caption + type
Outputs
  • history/sharp_group.json
  • Feeds next run's context
Feedback loop Engagement tracking No repetition
8
Publish to Social Media
Engine: Platform APIs
The selected image variant and its caption are posted directly to social platforms via their official APIs. The system handles authentication, media upload, caption injection with hashtags, and post scheduling — making the human's only job choosing which of the 4 variants to go live with.
Inputs
  • Selected post image
  • Albanian caption
  • Hashtags
Outputs
  • Live Instagram post
  • Live TikTok post
  • Engagement metrics back
Instagram API TikTok API Auto-caption

Brand Enforcement
How Brand Consistency is Enforced
BRAND.md is injected into every single AI call — not just once, at every stage.
🎨
Color System
Three strict colors: ■ Off-white #F9F9F9 background, ■ Orange #FF680B accent, ■ Black #000000 text. Any AI call that proposes anything outside these is overridden.
🔤
Typography
Poppins font, Bold and SemiBold weights only. Headlines up to 15 words max. All on-image text is Albanian. Logo placed top-center, scaled to 900px width.
📐
Composition Rules
4:5 vertical format (1080×1350px). 3D objects fill lower 40% of frame. Top center is reserved for logo and headline. No objects compete with text.
💬
Voice & Tone
Performance-first, strategic, direct. Never motivational fluff. All captions end with the fixed CTA: "Behu me i mprehte me ne." — every single time.
