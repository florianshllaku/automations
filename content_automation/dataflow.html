Brand Enforcement
How Brand Consistency is Enforced
BRAND.md is injected into every AI call — Step 1, Step 3 — and the render templates encode the visual rules in HTML/CSS.
🎨
Color System
Three strict colors: off-white #F9F9F9 background, orange #FF680B accent, black #000000 text. The orange template inverts to a saturated orange field with white text. Any AI suggestion outside this palette is overridden by the template.
🔤
Typography
Poppins, Bold and SemiBold only. Headlines max 15 words. Highlight spans render in brand orange. JavaScript auto-fits the headline so long copy and short copy both look intentional.
📐
Composition Rules
4:5 vertical (1080×1350). Logo top-center, headline below, optional accent line / CTA button on the left. Hero objects live in the lower 40% so nothing competes with the text block.
💬
Voice & Tone
Performance-first, sharp, no motivational fluff. Captions always end with the fixed phrase "Behu me i mprehte me ne." — enforced by the GPT prompt itself.
🔁
Style Alternation
The pipeline reads the previous post's visual description and forces the next post into the opposite mode — 3D abstract graphics ↔ real-person editorial — so the feed never looks repetitive.
🚫
No-Repeat Memory
GPT receives the last 3 post types and last 5 headlines as a block list. Any duplicate is rejected before generation, not after.
Run Sequence
A Post is Born in ~2 Minutes
T + 0s
Command fires
py generator.py sharp_group — loads brand profile, reads post history, instantiates OpenAI / Gemini / Fal clients.
T + 5s
GPT writes the brief
OpenAI returns post type, theme, Albanian headline (with highlight spans) and caption. Anti-repetition blocks recent types and headlines.
T + 10s
3 references picked
A random sample of 3 past brand posts is drawn from uploaded_posts/ for the next two stages.
T + 20s
Gemini writes the prompt
Gemini reads BRAND.md + the 3 references, applies the style-alternation rule, and returns one detailed Fal.ai prompt with composition + lighting specs.
T + 35s – 90s
Fal.ai generates the background
References are uploaded and a single 4:5 image is rendered via gpt-image-2/edit. No text, no logos, brand palette only.
T + 95s
Playwright screenshots the HTML
Headless Chromium loads the chosen template (default or orange), JS auto-fits the headline, and a 1080×1350 JPEG is saved.
T + ~120s
Done. History updated.
Final post and raw background are written to output/<brand>/. The run is appended to history. Caption is printed to the console for copy/paste.
