# Project Rules for Claude

## Sharp Group Content — MANDATORY

**Before creating ANY content for sharp_group** (posts, image prompts, captions, overlays, visual directions, anything) you MUST:

1. Read `assets/sharp_group/BRAND.md` first
2. Follow every rule in that file strictly — visual style, tone, color system, typography, imagery, content direction
3. Never generate a prompt, caption, or image instruction without grounding it in BRAND.md

This applies whether the user asks directly ("create a post", "write a caption", "generate a prompt") or indirectly ("make something for sharp group").

BRAND.md is the single source of truth. It overrides any assumptions or defaults.
